# Cripto Dashboard

Um projeto pessoal desenvolvido em **React**, que exibe as principais criptomoedas em tempo real utilizando a API do [CoinGecko](https://www.coingecko.com/).  


---

## 🔗 Teste online via Vercel

Veja o projeto funcionando ao vivo: [Cripto Dashboard - Vercel](api-criptomoedas-eta.vercel.app)

---

## 🛠 Tecnologias utilizadas

- **React** – Biblioteca principal para construção da interface.  
- **JavaScript (ES6+)** – Lógica e interação do usuário.  
- **HTML5 & CSS3** – Estrutura e estilização responsiva.  
- **CoinGecko API** – Dados em tempo real das principais criptomoedas.  
- **Vercel** – Hospedagem e deploy contínuo.

---

## 📌 Funcionalidades

- Exibição das principais criptomoedas com:  
  - Nome e símbolo  
  - Preço em USD  
  - Variação nas últimas 24h  
  - Valor de mercado (Marketcap)
